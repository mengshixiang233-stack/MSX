# Copywriting Style

The writing should sound like a high-level scientific defense slide: accurate, concise, specific, and evidence-linked. It is not manuscript prose and not promotional copy.

## General Rules

- Do not write ordinary section labels when a scientific judgment title is possible.
- Do not use empty phrases such as “系统性、全面、显著、有效、深入探究、提供支撑、奠定基础、重要意义” unless the source/data directly justifies them.
- Do not make all text tiny fragments.
- Do not expand every label into a sentence.
- Keep explanation in speaker notes when the slide would become dense.
- Preserve necessary scientific terms: `Morris 水迷宫`, `2-VO`, `NO/iNOS/eNOS`, `p38 MAPK/NF-κB`, `GFAP`, `BDNF/TrkB/Akt`, `L-Asparagine`.

## Page Title

Titles should combine **research content + key finding**.

Good:

- `脑内稳态｜海马低灌注伴随谷氨酸升高`
- `胶质炎症｜GFAP 活化并与 p38 MAPK 信号共定位`
- `突触可塑性｜BDNF 轴下降并伴随突触分子异常`
- `机制整合｜胶质炎症链路推动认知损伤`

Avoid:

- `海马脑血流与谷氨酸代谢分析`
- `GFAP 与 p38 MAPK 共定位分析`
- `核心结果`
- `机制验证`

Titles may be longer than ordinary slide titles if needed for accuracy.

## Subtitle

Subtitle gives the evidence layer, mechanism-chain role, or study object. It should be short and must not collide with body content.

Examples:

- `机制链 02：行为表型进入海马微环境改变`
- `机制链 05：用通路抑制验证 p38 MAPK 的病理参与`
- `论文成果按机制环节推进，而不是并列论文罗列`

## Right-Side Bullets

Right bullets must be short scientific sentences tied to visible evidence.

Rules:

- Use native PPT large round bullets.
- Font: Microsoft YaHei, 18 pt.
- Usually 3 bullets; max 4.
- Each bullet should mention an observation and its interpretation or mechanism position.
- Avoid generic `提示/支持/共同显示` repetition.
- Avoid line wraps leaving only 1-3 Chinese characters on the final line.

Bad:

- `CBF 下降`
- `谷氨酸升高`
- `稳态受扰`

Good:

- `ASL-MRI 图像和定量均指向海马 CBF 下降`
- `谷氨酸柱状图显示模型组水平升高`
- `低灌注与兴奋性代谢异常在同一阶段出现`

## Bottom Takeaway

Bottom takeaway is a full sentence, normally 28-55 Chinese characters. It changes function by page type:

| Page Type | Takeaway Role |
|---|---|
| Background | state necessity |
| Problem | define scientific gap |
| Route | explain design logic |
| Result | summarize core finding and mechanism role |
| Mechanism synthesis | close the evidence chain |
| Innovation | state project contribution/application entry |

Avoid repeated templates like “本页说明……”. Use specific mechanism language.

Examples:

- `脑血流与谷氨酸结果把行为损害推进到海马微环境层面，提示低灌注和代谢异常是机制入口`
- `GFAP 与 p38 MAPK 共定位将炎症放大定位到星形胶质细胞反应，是项目“胶质细胞网”的关键证据`
- `本项目将咬合支持丧失后的行为损害、低灌注、NO 失衡、胶质炎症和神经元损伤整合为连续机制链`

## Page-Level Rewrite Procedure

For every slide:

1. Identify page type.
2. Identify the one thing the audience should remember.
3. Select the main evidence.
4. Write title, bullets, and takeaway only after the figure hierarchy is known.
5. Check each bullet against a visible figure/panel.
6. Check length, wrap risk, and scientific overclaim risk before writing to PPT.
