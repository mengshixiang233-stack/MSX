# Page Types And Narrative

Use a mechanism-discovery arc: **background → gap → scientific question → design → evidence chain → mechanism synthesis → output support → innovation**.

## Page Types

| Type | Function | Typical Layout | Bottom Takeaway Function |
|---|---|---|---|
| Cover | Establish project identity and defense context | strong title, project metadata, one mechanism visual | project scope |
| Background | Explain clinical/scientific necessity | compact context visual + short bullets | why this matters |
| Problem | Define unresolved mechanism gap | schematic or structured question | scientific gap |
| Route | Show how the question is tested | full-width workflow or design grid | design logic |
| Result | Advance one evidence step | main figure + right evidence rail | core finding |
| Mechanism synthesis | Close the evidence chain | large central mechanism model | whole-chain conclusion |
| Output/achievement | Relate papers/results to mechanism nodes | timeline, not dense table | cumulative support |
| Innovation | State project contributions and next steps | 3 concise innovation blocks + future directions | contribution and application entry |

## Default Deck Structure

1. Cover / project overview
2. Research background
3. Existing evidence and mechanism gap
4. Scientific problem
5. Scientific question and evidence modules
6. Project mainline / evidence-chain design
7. Multi-model route and detection system
8-17. Core results by mechanism chain
18. Total mechanism synthesis
19. Paper/output mechanism timeline
20. Innovation and future directions

Adjust slide count to the user’s target, but keep the order: no result slide before problem/design unless the user asks for a claim-first talk.

## Core Result Mechanism Chain

Use this sequence for tooth-loss / neurobiology / medical mechanism projects by default. Rename nodes when the project differs, but preserve the logic of progressive mechanism evidence.

| Chain No. | Node | Role |
|---|---|---|
| 01 | 行为表型 | establish interpretable functional phenotype |
| 01b | 表型稳健性 | show multi-model or multi-background repeatability |
| 02 | 脑内稳态 | connect phenotype to brain microenvironment |
| 03 | NO/血管通路 | connect perfusion/vascular state to inflammatory entry |
| 04a | 胶质炎症 | show inflammatory pathway activation |
| 04b | 胶质炎症细胞定位 | locate pathway to glial response/cell network |
| 05 | 通路干预 | provide causal/pathway involvement evidence |
| 06 | 神经元损伤 | show tissue/cell survival endpoint |
| 07 | 突触可塑性 | explain learning-memory network instability |
| 08 | 系统轴线 | extend to peripheral/system axis when evidence exists |
| 09 | 机制整合 | close the full mechanism chain |
