# Page-Level Example

This example shows how a dense result topic becomes one v11-style evidence-chain slide.

## Input Material

Topic:

`海马脑血流与谷氨酸代谢分析`

Available figures:

- `10-cbf.jpg`: ASL-MRI images and hippocampal CBF quantification.
- `10-glutamate.png`: glutamate column chart.

Raw interpretation:

The model shows decreased hippocampal cerebral blood flow and increased glutamate. This connects behavioral impairment to brain microenvironment changes.

## Page Classification

| Field | Decision |
|---|---|
| Page type | result page |
| Mechanism-chain node | `02 脑内稳态` |
| Core finding | hippocampal hypoperfusion occurs with glutamate elevation |
| Main evidence | `10-cbf.jpg` |
| Secondary evidence | `10-glutamate.png` as enlarged inset |
| Backup decision | no need to show unrelated premise figures |

## Final Slide Text

Title:

`脑内稳态｜海马低灌注伴随谷氨酸升高`

Subtitle:

`机制链 02：行为表型进入海马微环境改变`

Right bullets:

- `ASL-MRI 图像和定量均指向海马 CBF 下降`
- `谷氨酸柱状图显示模型组水平升高`
- `低灌注与兴奋性代谢异常在同一阶段出现`

Bottom takeaway:

`脑血流与谷氨酸结果把行为损害推进到海马微环境层面，提示低灌注和代谢异常是机制入口`

## Layout

- Main image: left evidence area, about `x=1.76, y=1.42, w=6.58, h=2.58`.
- Inset: enlarged glutamate chart under/right within evidence area.
- Right evidence rail: `x=8.55, y=1.46, w=4.25, h=4.35`, native round bullets, 18 pt.
- Bottom takeaway: y about `6.36`, 18 pt.
- Source label sits above takeaway and does not overlap the inset.

## Why This Works

The slide does not say merely “CBF 下降 / 谷氨酸升高.” It shows the main CBF evidence clearly, uses glutamate as a smaller but readable inset, and positions the finding as the mechanism-chain entry from behavior into hippocampal microenvironment.
